# 常见问题

[返回首页](../README.md) · [开发文档](DEVELOPMENT.md)

## 麦克风没有读数

检查选中的输入设备、系统是否允许输入及实际音量。使用第一声道，外置双通道接口接第一路；实时范围为 60–1600 Hz。

## 音高跳八度或读数抖动

工具针对单音。伴奏、多个人声、噪声、弱基频和气声都可能影响识别，先用稳定元音及较安静环境比较。

## 显示到 0.1 音分是否代表同等准确度

不是，显示精度与实际测量准确度不同，声卡时钟及录音条件也会影响结果。合成测试结果不能当作真人演唱计量认证。

## 复盘窗口隐藏后录音还在吗

单独隐藏窗口不会清空当前数据或中断录音。整个应用退出与隐藏窗口不同；先结束录音并确认保存。

## 解压后程序缺少 DLL

便携包需要保留相邻 _internal 文件夹及其依赖，不只复制 EXE。校验同一 Release 提供的哈希文件。

## 历史截图或验证文件链接不存在

verification 是本机测试输出，不全部公开。使用仓库 README 中的现有截图，算法证据可通过公开测试重新生成。

## 仍无法解决

提交 Issue 时附版本或提交、系统环境、复现步骤与脱敏错误。优先提供合成文件，保留原数据与完整日志的本机备份。
